# 执行宿主：其他宿主或纯对话

宿主不明确或没有专门附录时使用。先回答能力自检，再按 [编排档位与授权](orchestration.md) 定实际档位；答不上来的按低一档写，并在确认块里询问用户。

## 能力自检

1. 能否派出看不到主会话历史的工作者，并收回结果？（决定能否用 L1）
2. 能否强制工作者只读？能否给每个工作者独立副本？
3. 有没有由运行时按脚本执行的编排？（决定能否用 L2）
4. 有没有会话级的自主编排开关？（决定能否用 L3）
5. 有没有持续执行机制？完成由谁判定，判定者能看到什么？
6. 能否看图、听声音？不能时，画面和声音的判断交给能看图的评审、用户或数值指标。

## 降级写法

- 没有子代理：独立评审改为“评审包”，包含目标、通过线、参照、证据路径和要回答的问题（反馈是否解决；最大的 3 个问题），交给新开的会话或用户，结论回填进度。
- 没有持续执行机制：按普通回合推进，进度写进文件以便接续；停止条件由执行方每轮自报。
- 完成由执行者自己判定时：主观项必须过独立评审并经用户确认；画面项未通过不得判完成。
- 授权：回复里写出档位（如“确认 L1”）；本宿主达不到的档位按降级写法执行。
- 启动：把 Goal 里的启动段作为提示发送，授权写成用户原话。
