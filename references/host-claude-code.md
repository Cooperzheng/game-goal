# 执行宿主：Claude Code

核实于 2026-10（Claude Code 2.1.305）。宿主升级后，先按文末“复查项”核对再用。本文只写对应关系和坑，通用规则见 [编排档位与授权](orchestration.md)。

## 档位对应

- **L0 → 不派子代理。** 包括检索类子代理和分叉（fork），全部由主会话完成。
- **L1 → 子代理。** Claude 会自行决定派出，Goal 写明用途、并发上限和适用预算，执行时遵守。强制只读需要一个工具白名单只有 Read（及 Glob、Grep）的自定义子代理（放在 `~/.claude/agents/` 或项目的 `.claude/agents/`；新建它属于改配置，要在 Goal 里列出并经确认）。没有时用内置的 Explore 等没有编辑工具的类型，但它们仍能运行命令，所以指令写明只读，汇报时附版本库状态核对。模块代理是否用独立 worktree（`isolation: worktree`）按 Goal 里写明的判断；用了就在收尾删除，它自带一套依赖、构建和临时产物。子代理默认后台运行，最多嵌套 3 层，同时最多 20 个（Goal 额度更小时以 Goal 为准）。
- **L2 → Workflow（动态工作流）。** 必须由用户授权：用户自己的话，例如回复“确认 L2”（确认块已写明 L2 的 Workflow 用在哪），或启动命令里写“允许使用 Workflow，限编排授权一节所列场景”。关键词 `ultracode` 和会话级 ultracode 也会触发 Workflow，见下文。Goal 文档里的文字只是记录，不是授权来源。运行中不能停下等确认，每个检查点段单独跑一个；脚本本身不读写文件，由其中的代理完成；同时运行约 16 个代理（受 CPU 核数限制）；默认的规模指引只是建议，Goal 写的上限会覆盖它；跑通的工作流可以保存成命令复用（如评审团）。
- **L3 → `/effort ultracode`。** 由用户开启，阶段结束用 `/effort ultracode off` 关闭。开启后每个实质任务默认编排、不把消耗当约束，大型工作流警告和并发子代理上限都不再生效，所以 Goal 必须同时写禁区和额度。

## 防止擅自编排

- 档位低于 L3 时，开工前确认会话没有开 ultracode：没有收到 ultracode 已开启的提示；不确定时请用户用 `/effort` 查看。已开启就先请用户执行 `/effort ultracode off`，再开始。
- 用户消息和启动命令里不出现 ultracode 这个词，指代时写“会话级自主编排”：这个词会把该条消息的任务直接做成一个工作流，不等于“允许使用”。误触时按 Alt+W（macOS 为 Option+W）取消高亮；也可以在 `/config` 关闭关键词触发。
- 每轮状态块报子代理和 Workflow 的累计用量；独立评审按整体预算与局部停滞条件推进，显式额度耗尽只停受限活动、继续独立工作并询问。
- 工时上限要能核对：进度行带时间戳（用 `date` 等命令取），暂停与恢复各记一行，最后一条消息写总工时和算法；`/goal` 的判定模型看不到时钟，只能读这些记录。
- 估算用量前先查 effort 与模型映射：环境变量设定的 effort 会覆盖子代理自己的 effort 设置；若所有代理都按同一高档模型运行，按此估算。

## 磁盘与会话记录

- 看过的图会连同图像数据存进本机的会话记录，看得越多记录越大、上下文也越早压缩：评审图先裁切、缩小，一次限量。
- 会话记录默认保留 30 天（`cleanupPeriodDays`）。要靠会话复盘的项目，在节点时把对应会话收进项目历史。

## 启动与判定

- 短任务：用户回复确认后直接执行。
- 长任务：确认后写入 Goal 文档，再由用户发出启动命令，例如：
  `/goal 完成[……]，唯一依据是[Goal 文档]。编排按「编排授权」一节：允许子代理（[用途]）[及其中列出场景的 Workflow]，其余不用。完成条件：[……]；画面项未通过不得判完成。`
- `/goal` 每回合结束由另一个模型判定是否完成；它不调用工具，只看对话。品质类目标的条件要写画面验收结果（参照对比、评审结论、廉价感清单、待用户确认项），功能检查通过不构成完成。完成证据要贴在对话里，最后一条消息集中列原始结果行；长任务会压缩上下文，前面贴过的证据可能看不到。条件最多 4000 字符：细节放 Goal 文档，条件里写可证明的终态、约束和轮数／时间上限。后台子代理或命令仍在运行的回合会跳过判定。

## 安装与调用

- 个人目录 `~/.claude/skills/game-goal/`，项目目录 `.claude/skills/game-goal/`；可以用目录链接指向其他宿主的同一份副本。
- 默认按描述自动触发。想只在点名时用：在 settings 里设 `"skillOverrides": {"game-goal": "name-only"}`（Claude 只看到名字，说“用 game-goal”仍能调用），更严格用 `"user-invocable-only"`（只能输入 `/game-goal`）。不要在 SKILL.md 里加 `disable-model-invocation`，上传或打包到其他平台时会报错。

## 复查项

子代理的只读与隔离写法；Workflow 的授权方式、并发与规模指引；ultracode 的行为与关键词触发；`/goal` 的判定方式与条件上限；`skillOverrides` 的取值。
