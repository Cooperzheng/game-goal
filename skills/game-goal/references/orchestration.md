# 编排与执行

## 选择最小档位

| 档位 | 允许机制 | 典型用途 |
|---|---|---|
| L0 | 只有主会话，不派任何子代理 | 集中的客观小改动；用户评审主观项 |
| L1（默认） | 子代理 | 独立评审、调研、文件不重叠的模块 |
| L2 | 加限定场景的脚本化编排 | 多对象多轮对比、评审团、批量检查或较多独立模块 |
| L3 | 加会话级自主编排 | 明确授权的调研、审计或终验阶段 |

不为使用机制而升档。推荐写一句理由，复杂任务才比较取舍。默认同时最多 3 个子代理；脚本化编排每次最多 5 个代理，评审团默认 3 人，每轮最多一次。用户另有约定时从其约定。

独立评审不默认设累计人次、总编排次数或单项轮数上限，按整体预算与局部停滞推进；用户明确指定硬额度时才设并预留终验用量。非评审用途写适用的总额度。预计用量按每轮人数和预计轮数估算，不当作停止条件。

## 授权与职责

- 用户消息才是授权来源，文档用于记录。只回“确认”时按不高于推荐的 L0/L1 执行；L2/L3 必须明确写出档位。档位是上限，范围内无需逐次问；升档、追加硬额度或扩大用途需确认。授权只对本 Goal 有效。
- 子代理、脚本化编排、会话级自主编排分别写明用途；未用机制合并注明不用。L3 写出消耗与大规模编排代价，不用于耦合美术实现；低于 L3 开工前核对未启用会话级自主编排，无法确认时询问，已启用则先关闭。
- 光照、材质、后处理、特效及共享核心文件等耦合系统，由主会话一人顺序修改。并行前明确接口、文件归属、共享参数和构图空间。
- 评审只读，模块代理只改列明文件；代理不推送、不发布、不安装全局工具、不删除主工作区文件。合并由主会话负责。宿主不能强制只读时用指令约束，并核对版本库状态。
- 隔离副本按需开：支线需各自构建、截图或长期独立运行时写明理由与收尾方式；文件互不重叠、可统一验证时共用分支即可。共用分支的子代理不提交，主会话合并后统一构建、截图、试玩。保护其他会话的工作区和进程。
- GPU 性能测量与基线截图串行，不与其他吃 GPU 的任务同时运行；帧时间只认 GPU 空闲时的测量。代理长期无进展时接手或重开，失败仍计入用量。
- 每次编排后简报用途、人数、结论与累计用量。显式额度耗尽只停受限活动，继续独立工作并询问追加；降档可自主决定并记录损失与补偿。

## 预算与停止条件

整体轮数／工时、计数口径和恢复方式由用户确认，不自行发明预算，不把游玩时长当工作预算。可约定累计 N 轮和／或 T 小时，同时采用时先到者触发。轮数可按一次“诊断→修改→复查”计，失败也计；工时按实际经过的工作时间，并行不相加，全部暂停的等待不计。换代理或模块不清零。

默认局部停滞为同模块同一差距连续 2 轮无可验证改善；用户另有指定时从其指定。只暂停该项及依赖项，其他独立工作继续；局部待确认或阻塞同理。整体预算到达、剩余工作全部受阻或必须改变共同约束时才整体暂停。记录时间戳、版本、尝试、累计用量和恢复条件；暂停不算完成，等待不等于批准。回归失败先修复或撤回，不用停滞规则豁免。

## 执行前核实宿主

依据当前工具、权限和官方说明核实，不把某个版本的命令与默认值固化为通用规则：

- 能否派独立上下文工作者、强制只读、隔离文件；有无脚本化和会话级自主编排；实际模型、推理强度和并发限制。
- 持续执行由谁判断完成、能看到哪些证据与时钟、如何暂停；把完成标准与停止条件同时写进启动提示和 Goal，对话保留最新结果与时间记录。
- 无子代理则把目标、通过线、参照、证据和评审问题交新会话或用户；无脚本化机制则降到 L1 按清单调度；无持续执行机制则普通回合推进并保存接续信息。写明推荐档位、实际档位、损失与补偿。
- 无看图、听声音或真实输入能力时，相关体验交有能力的评审或用户验证，数值仅补证。不能因工具受限而标通过。
- 核对机制是否存在关键词自动触发，避免启动提示误开更高档位。不要为了执行 Goal 擅自改宿主配置。图片可能进入会话记录，评审按需查看有效证据，不反复加载整套图。

## 写入 Goal 的执行约定

只填适用项；详细要求各写一次：

> 宿主 [名称]，推荐 [Lx]、实际 [Ly]，用于 [用途]；其余机制不用。子代理并发 [N]，脚本单次 [N]、每轮 [N]；非评审总额度 [N／不用]，独立评审按整体预算推进 [或用户指定额度]。耦合系统由 [负责人] 顺序修改，代理文件边界 [范围]，隔离副本 [需要与理由／不用]。整体预算 [N 轮／T 小时与计数口径]；同项同一差距连续 [2] 轮无改善只停该项及依赖项，整体停止与恢复按 [约定]。
>
> 临时目录 [路径]，清理授权范围 [清单或明确边界]；调参只拍必要机位，复用有效证据，完整检查集中在稳定候选与必要交付节点。每轮新证据验证后、下一轮前清理被替代产物；500 MB 兜底触发整理，不等最终收尾。保留基线、当前有效证据、必要对照与最小失败样本；完整原片单列，原件及范围外内容不动。用户验收默认 1–2 张重点板、完整机位备查，不因此漏必要证据；收尾更新引用并简报体积。

独立执行时把适用的权限、回归保护、主观验收、录像项和停止条件写实，不能留下仅指向 Skill 的占位指令。
